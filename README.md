One line, 44 characters: a job title that sounds like a real corporate role with one specific absurd twist. Senior Manager of Apologizing to Angry Geese.

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–60 characters, single line, not only white space), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
